# 우리동네 조사단 · 주민 브리핑

사이트: https://diidii56.github.io/-/

`index.html`을 수정하고 `main`에 반영하면 GitHub Actions가 자동으로 배포합니다.
주소가 그대로 유지되므로 같은 QR을 계속 사용할 수 있습니다.

최초 설정: 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다.
배포 진행과 오류는 Actions의 **Deploy website to GitHub Pages**에서 확인합니다.

로컬 확인: `python3 -m http.server 8000`

현재 글꼴은 NAVER의 나눔스퀘어라운드입니다. 글꼴 출처: https://hangeul.naver.com/font
웹폰트 제공: https://github.com/innks/NanumSquareRound
글꼴에 포함된 저작권 정보는 `NanumSquareRound-LICENSE.txt`에 보존했습니다.
