# 만족도 조사 연결 (최초 1회)

1. Google 스프레드시트를 새로 만들고, **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 코드를 지우고 이 폴더의 `Code.gs` 내용을 붙여 넣고 저장합니다.
3. 위 함수 선택에서 **setup**을 선택해 실행하고 Google 권한을 승인합니다. `만족도응답` 시트가 만들어집니다.
4. **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 사용자: **나**, 액세스 권한: **모든 사용자**. Google Workspace 정책 때문에 이 옵션이 없으면 관리자 허용이 필요합니다.
5. 배포된 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다. `/dev` 주소가 아닙니다.
6. `assets/survey-config.js`의 빈 따옴표 안에 이 주소를 넣고 main에 반영합니다. 웹 앱 주소는 공개 주소이며 비밀번호나 API 키는 넣지 않습니다.
7. 웹사이트에서 평가를 한 번 제출합니다. 시트에 행이 생기고, 다른 브라우저에서 참여 수와 평균이 갱신되는지 확인합니다.

스프레드시트 자체는 공개 공유하지 마세요. 웹 앱은 응답 작성과 집계 수치만 공개합니다. 자유 의견은 공개 API로 반환하지 않습니다.
서버 코드 변경 후에는 **배포 관리 → 편집 → 새 버전**으로 배포하세요. 같은 배포를 수정하면 주소가 유지됩니다.

## 운영상 한계

15초 간격으로 집계를 읽으며 제출 직후 바로 읽습니다. Apps Script 실행 할당량에 영향을 받으므로 다수 동시 접속 시 갱신 간격을 늘리거나 별도 데이터베이스로 이전하세요.
익명 공개 설문입니다. 동일 제출 번호는 서버에서 중복 저장하지 않고, 같은 브라우저의 재제출을 제한합니다. 브라우저 변경·저장소 초기화·직접 요청까지 차단하는 본인 인증은 아닙니다.
응답 시각, 점수, 자유 의견과 임의 응답번호를 수집합니다. 공개 전에 운영자는 보관 기간과 삭제 절차를 정하고 필요한 개인정보 고지를 검토하세요.

점수 없이 자유 의견만 제출할 수 있습니다. 의견만 있는 행은 점수 칸을 비워 저장하며 만족도 평균과 점수 평가 건수에서 제외합니다. 이 기능을 적용하려면 Code.gs를 교체하고 기존 웹 앱 배포를 **새 버전**으로 갱신하세요. 배포 주소를 유지하세요.
